Using Chrome/Firefox DevTools allows live tweaking of CSS variables and font rules.

Why I Chose These Colours:

1. The primary blue color (#2563eb) provides a modern, professional feel that instantly highlights key elements.

2. Light background gray (#f4f4f9) with pure white cards (#ffffff) ensures high contrast and clean visual separation.

3. Dark charcoal gray (#4b5563) for body text prevents eye strain compared to harsh pitch-black text.
